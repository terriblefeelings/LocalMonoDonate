02Background

03Media Parameters
A donated video plays only if the amount ≥ YouTube min ₴, it has ≥ min views and is ≤ max minutes. Playlists are accepted only when allowed.
Other media
Enabled link types
Instagram, TikTok, Twitch clips, Reddit and X links only need the minimum amount; views and duration are not checked.
Sound alerts selector
How donors pick sound alerts on the donation page. Single: one alert from a list. In order: pick several, they play one after another before the donation. ADHD: the same picker, all chosen alerts play at once.
Test alerts
Plays on the sound-alerts overlay using the first alert (single) or the first three (order / ADHD). No donation is recorded.
