## 1. First run & links

**What do I absolutely need for the app to work?**
Monobank API token + at least one jar. Everything else is optional; without a jar the donation page
shows “No jar configured” and the Pay button stays disabled.

**Where do I get the token and jar code?**
Token: <https://api.monobank.ua> (or Monobank app → Settings → API). Jar: copy only the code from
`send.monobank.ua/jar/<CODE>`.

**Which link do I give viewers?**
Never `*.localhost` — that only works on your own PC (OBS). For viewers use the Tailscale URL:
`https://<tailnet>/<nickname>/donation`. See [§11](#11-tailscale--the-public-page).

**Why did my old link stop working after I changed the nickname?**
Every host must start with the current nickname; `oldname.donate.localhost` now returns 404 by design.

**What is “My jar”?**
Untick it for a third-party jar: the donation page gives a payment link, but the app cannot read its
statements, so there are no alerts, codes or history for it.

**Can I run several jars at once?**
Yes, up to 5. All are polled; each has its own history and stats.

## 2. Donations & matching

**How does the app know which pending donation a bank payment belongs to?**
1. By **code**: the comment contains `донат сповіщення <code>` (the code is generated by the donation page).
2. Otherwise by **amount + recency**: same jar, amount within ±max(1 ₴, 2 %), created in the last hour.

**What happens to an unmatched payment?**
It still goes to history and stats. It alerts only if *Notify unmatched payments* is on; its name is
the bank sender name, or `Anonymous` when empty.

**Do donations without a nickname work?**
Yes — the donation form allows an empty name and the app records it as **Anonymous** (sound alerts
become **Anonymous SA**).

**Why is there a delay between paying and the alert?**
The app polls Monobank: fast (15 s) shortly after a form was opened, then 60 s, then the idle interval
(default 60 s). You can change `poll_seconds` / `idle_poll_seconds` in `config.json`.

**Are old donations re-alerted after a restart?**
No. On the first poll the last 30 days are imported **silently** (history/stats only). Only live
payments alert.

**Can I replay an alert?**
Yes — in the history UI the replay button re-broadcasts that donation to the overlay. Replays are
local only (no StreamElements tip).

## 3. Alert overlay

**How do I add the overlay to OBS?**
Browser source → `http://<nick>.overlay.localhost:8787/main` (1280×720 or 1920×1080), then “Refresh
cache of current page” after changing styles.

**The overlay shows nothing.**
Check: overlay feature enabled in *Links*, the page is the overlay URL (not `/setup`), and the browser
source has a transparent background / correct size.

**Which overlays exist?**
`/main` donations, `/bits` sound alerts, `/timer` marathon timer, `/youtube` video player. All are on
`<nick>.overlay.localhost`.

**How do I test an alert without donating?**
On `/notify` use the preview/test button, or `POST /api/test` with `{ "name": "Test", "amount": 100,
"message": "hi" }`. Tests never reach StreamElements.

## 4. Alert styles / notify rules

**Where do I edit how alerts look?**
`/notify` — it previews on the left and edits on the right. Each rule has an amount range
(`from`/`to`), timings, text template, image/background and TTS behaviour.

**How does rule selection work?**
First matching range wins; the `Default` rule is the fallback for anything outside the other ranges.

**Can different amounts look different?**
Yes — create one rule per range (e.g. 10–99, 100–499, 500+). They apply to donations; sound alerts use
their own overlay.

**Where do images/backgrounds come from?**
Upload them in the editors (`/donateedit`, `/notify`); files are copied to
`%APPDATA%\LocalMonoDonate\media\`.

**Placeholders in text?**
`%donate%` = donor name, `%money%` = formatted amount. Both are replaced per alert.

## 5. Sound alerts (bits)

**What is a “bit”?**
A purchasable sound/video/image alert with a fixed price and a code. Viewers buy it on
`/bits`; the payment comment carries the code, the app plays it on the bits overlay.

**How do I create bits?**
`/bitsedit` — label, price, kind (sound/video/image/alert), media URL, optional button image, code.

**What is the nickname field on the sound-alerts page for?**
Stats/StreamElements attribution. With a nickname the alert counts as `<nick> SA`; empty means
`Anonymous SA`. The nickname travels in the payment comment (`… | name: <nick>`).

**Do bits count toward the timer or StreamElements?**
They add timer time like a donation, and when StreamElements is enabled they are mirrored as a tip
named `<nick> SA`. They do not create a regular donation alert.

**A bit plays nothing.**
Check the media URL (direct file, not a page), the bit code matches the comment, and the bits overlay
is open. Preview the file with the ▶ button in the deck.

**How many bits can I have?**
No hard limit; the deck grid is 2–7 columns (`bits_grid`).

## 6. Marathon timer

**How does time get added?**
`amount / per_amount * per_seconds`, only for donations ≥ `min_donation`. Example: 10 ₴ → 60 s with
per_amount 10 and per_seconds 60.

**Do Twitch subs add time?**
Yes when the timer feature and Twitch are enabled: tier 1/2/3 seconds are separate settings; gifted
subs multiply by the gift count.

**Where do I control it?**
`/timeradmin` — start/pause/add/subtract/reset and edit the rules; overlay at `<nick>.overlay.localhost/timer`.

**The timer stops after a restart.**
By design: a running countdown is frozen on shutdown and resumes only after you press Start.

**Can I use the timer without donations?**
Yes — add time manually in `/timeradmin`; donations are just the automatic source.

## 7. Auction

**Where is the auction?**
Standalone page on its own port: `http://<nick>.auction.localhost:8788/` (settings at
`/auctionsettings`, which also runs on the main app port).

**Where do bids come from?**
Donations (amount ≥ `min_bid`), Twitch channel-point redemptions, and manual entries in the auction UI.
Sources can be filtered; identical redemption ids are deduped.

**What are lots?**
Named items the auction is for. Lots appear automatically from bids or can be created/edited/pinned
in the UI; bids can be adjusted or deleted.

**How is the winner chosen?**
Weighted by bid amount across the active lots, with a manual override. History is local.

**Do auction bids count as donations?**
They are separate: no donation alert, no timer time, no StreamElements tip.

## 8. Twitch

**What do I need?**
A Twitch application (confidential) with the redirect URL shown in Setup:
`http://localhost:8787/twitch/callback`. Paste Client ID + Secret, press *Authorize Twitch*, log in.

**What does it read?**
EventSub WebSocket: `channel.subscribe`, `channel.subscription.gift`,
`channel.subscription.message` (timer) and `channel.channel_points_custom_reward_redemption.add`
(auction). Scopes: `channel:read:subscriptions channel:read:redemptions channel:manage:redemptions`.

**Do I need a public URL or a Cloudflare worker?**
No. OAuth is local and EventSub connects outbound over WebSocket.

**Does it create the channel-point rewards?**
Yes, on first connect for the auction it creates (or reuses) rewards for each configured cost.

**Token expired / not connecting?**
Reconnect in Setup → Authorize Twitch. Tokens are in `%APPDATA%\LocalMonoDonate\<port>\twitch.json`.

## 9. StreamElements

**What does the integration do?**
Every live donation and sound alert becomes a StreamElements **tip** (real currency) so your SE alert
box can play, plus a matching activity so it also shows in the Activity feed and dashboard stats.

**Why are dashboard amounts in USD?**
SE activities have no currency field; SE totals are USD. The app converts using a live USD rate (6 h
cache) for the activity, while the tip itself keeps UAH/EUR/USD.

**How are tippers grouped?**
By **nickname only**. Same nickname = one tipper even with a different card/email; different nicknames
never merge. Anonymous donations count as `Anonymous`; anonymous sound alerts as `Anonymous SA`.

**Where do I configure it?**
Setup → StreamElements: account id + JWT (Settings → Account → API token), *Test connection*, then
the enable switch in *Links*.

**Does disabling really stop everything?**
Yes — with the switch off the app makes no StreamElements request at all (no tip, no activity, not
even the rate lookup).

**Nothing appears in SE.**
Check the log for `streamelements:` lines, run *Test connection*, make sure the donation actually
alerted (matched or unmatched allowed), and that the switch is on.

## 10. Voices / TTS

**What is the default?**
Google Ukrainian + Google English, free, no key — needs internet.

**How do I use Azure voices?**
Alerts → voice set → Azure, paste your own Speech key + region. Azure voices only appear once both
are set; usage is billed by Microsoft.

**Where are the custom StyleTTS voices?**
Only in full builds that include the StyleTTS2 model (~157 MB). The lite release ships Google/Azure,
so the “custom” set is hidden automatically.

**Can the donor pick a voice?**
Yes, when the voice set is “ALL” (default), the donation form shows a picker. Otherwise the streamer’s
default voice is used.

**What gets read aloud?**
`read_mode`: `message`, `announcement` (name + amount template) or `both`.

**No audio on the overlay.**
Browsers block autoplay — click once inside the OBS preview or enable audio in the browser source. Also
verify `tts-engine\` exists next to the exe.

## 11. Tailscale & the public page

**Why can’t viewers open the donation link?**
`*.localhost` is local-only. Use Tailscale: Setup → *Connect Tailscale* (installer ships with the
release), log in once, and the public URL becomes `https://<tailnet>/<nickname>/donation`.

**Does the app create the tunnel itself?**
It runs `tailscale up` for login and keeps `tailscale funnel` pointed at the public port (`8080` by
default) with the hostname set to your nickname.

**What is exposed?**
Only the donation page and the sound-alert deck. Admin pages and overlays stay local.

**I moved networks / restarted.**
Tailscale reconnects automatically; press *Reconnect* if the status is not “running”.

**Can I use my own domain instead?**
Yes, advanced: port-forward to `publicPort`, terminate HTTPS yourself and set `public_base` /
`public_port` in `config.json` so links point at your domain.

## 12. YouTube requests

**How does it work?**
The donation form accepts a YouTube link. If the donation reaches the rule’s `yt_min`, the video plays
in the YouTube overlay after the alert.

**Why was my link rejected?**
Only YouTube URLs/IDs are accepted, and the rule can also require a minimum view count or maximum
length. Those limits are in the notify rule (`yt_views`, `yt_max_min`).

**Where does it play?**
`<nick>.overlay.localhost/youtube` (own browser source), not the alert overlay.

## 13. Stats page

**Where is it?**
`http://<nick>.<statsCode>.localhost:8787/stats` — the code is generated when you press ↻ in Setup.
Regenerating invalidates the old link.

**What does it show?**
Totals, top donors (nickname-based, ties broken by the oldest donation), history with replays, and
per-jar balance/goal.

**Is the stats link public?**
No — `/stats` is not on the public listener. Keep the code private; it is a secret in the URL.

## 14. Config, secrets, ports

**Where are my settings?**
`%APPDATA%\LocalMonoDonate\config.json` (no secrets) and `data.json` (jars/history/timer/auction).
Nothing is stored in the app folder.

**Where are credentials?**
`%APPDATA%\LocalMonoDonate\<port>\`:

```
token                 Monobank API token
twitch.json           client id/secret + OAuth tokens
streamelements.json   StreamElements JWT
```

They are shown in the UI as blurred text with Show/Hide. Deleting a file resets only that credential.

**How do I change ports?**
Edit `port`, `auctionPort`, `publicPort` in `config.json` and restart. Every local link follows `port`.

**Can I move the app?**
Yes — the folder is portable; settings stay in `%APPDATA%`.

## 15. Logs & troubleshooting

**Where is the log?**
`%APPDATA%\LocalMonoDonate\LocalMonoDonate.log`.

| Log / symptom | Meaning |
|---|---|
| `Unknown 'X-Token'` | Monobank token wrong/revoked |
| `HTTP 429` from Monobank | too many requests — increase `poll_seconds` |
| `server.js`/`server exited` | not this app (that belongs to RatCorporation) |
| `streamelements: HTTP 401` | SE JWT expired — paste a fresh one |
| `tts daemon unavailable` | `tts-engine` missing or blocked |
| Blank donation page | no jar / page disabled in *Links* |

**WebView2 error at start?**
Install WebView2 (the app runs the bundled bootstrapper silently on failure).

**Port already in use?**
Change `port` in `config.json`; the auction port must differ from it.

## 16. Updating & backups

**How do I update?**
Replace `LocalMonoDonate.exe` (and `tts-engine\` if the release changed it) — settings and secrets stay
in `%APPDATA%`.

**How do I back up?**
Copy `%APPDATA%\LocalMonoDonate\` (config, data, tokens, media). Never commit it.

**How do I reset everything?**
Close the app and delete that folder; the next start is a fresh install.

---

## 17. Privacy

**What leaves my machine?**
Monobank API, Tailscale (if connected), Twitch/StreamElements (if enabled), and Google/Azure for TTS.
Nothing else; no analytics, no telemetry.

**Are tokens ever sent to the browser?**
Only to the local admin page (so you can see/edit them), blurred by default, never to the public
listener or embedded in HTML files.

## 18. Build, tests, packaging

**Build**
```powershell
cargo build --release
```
`public/` is embedded with `include_str!` — rebuild after editing HTML/JS/CSS.

**Tests**
```powershell
cargo test --release
cd AUC
$env:LMD_DATA = "$env:TEMP\lmd-tests"   # isolate from your real profile
node _alltest.mjs
node combotest.mjs
node _deeptest.mjs        # needs playwright-core
```

**Package**
```powershell
powershell -File pack.ps1 -WithTts -TtsEngine <path-to-lite-tts-engine>
```
Produces `dist\MONOBANK-lite-<version>.zip` with exe, WebView2 loader/bootstrapper, Tailscale MSI,
TTS engine and a blank `config.example.json`; no config, no secrets, no media.
